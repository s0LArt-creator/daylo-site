# Daylo Website 1.1 — Windows 10 + Windows 11

Статический сайт для GitHub Pages. Внутри адаптивный дизайн, описание Daylo, выбор тёмной/светлой темы и две кнопки скачивания.

## Публикация

1. Откройте репозиторий `https://github.com/s0lart-creator/daylo-site`.
2. Загрузите **содержимое этой папки** в корень `main` (замените `index.html`, `style.css`, `script.js`, `config.js`, `README.md` и `favicon.svg`). В интерфейсе GitHub при загрузке файлов с теми же именами может потребоваться подтверждение замены; при необходимости редактируйте файлы по одному.
3. GitHub Pages автоматически заново опубликует сайт. Можно проверить в Actions.
4. Windows 11 кнопка ведёт на активный EXE из последнего релиза (или страницу релиза, если API недоступен).
5. Кнопка Windows 10 **останется неактивной**, пока в последнем релизе не появится отдельный EXE, чьё имя содержит `Win10`, например `Daylo_Setup_7.0.9_Win10.exe`.
6. После теста Windows 10 прикрепите EXE к существующему релизу v7.0.9; менять `script.js` или создавать новый релиз не нужно. Кнопка активируется автоматически при успешном запросе к GitHub API.

**Безопасность**: не добавляйте базы задач, локальные резервные копии, токены или приватный исходный код приложения в публичный сайт.

Сайт использует `https://api.github.com/repos/s0lart-creator/daylo-site/releases/latest`, поэтому при временном сбое API Windows 10 может показываться как ещё не подтверждённая, но Windows 11 останется доступна через страницу релиза.
