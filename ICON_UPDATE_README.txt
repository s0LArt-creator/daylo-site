Веб-сайт Daylo с официальной иконкой D + календарь.

Загрузи содержимое папки в корень daylo-site через GitHub: Add file → Upload files → Commit changes. Заменить файлы index.html и style.css; загрузить новые favicon.png и daylo-512.png.

В config.js должна оставаться строка window.DAYLO_REPO = 's0lart-creator/daylo-site'; (перед публикацией проверь).
